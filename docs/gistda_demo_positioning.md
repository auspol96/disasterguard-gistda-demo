# GISTDA Demo Positioning

## Main Message

DisasterGuard is designed as a **multi-sensor disaster-priority intelligence layer**.

It does not replace existing disaster-monitoring platforms. Instead, it helps operators decide which geolocated areas deserve earlier review, revisit, alerting, or response coordination.

---

# Why This Positioning Matters

GISTDA already has strong capabilities in areas such as:

```text
Fire Hotspot monitoring
Crop Drought / เช็คแล้ง
THEOS-2 optical imagery
satellite-based disaster monitoring
multi-agency disaster data integration
```

Therefore, DisasterGuard should not be positioned as another fire map, drought map, or satellite dashboard.

The correct positioning is:

```text
A decision-priority layer that sits above multiple existing data sources.
```

---

# What DisasterGuard Adds

DisasterGuard helps answer operational questions such as:

```text
Which area should be reviewed first?
Which incident is escalating?
Which location may impact people or infrastructure most?
Which area should be revisited or monitored more closely?
Which case should be escalated for response coordination?
```

---

# Complementary Role

DisasterGuard can complement existing systems by combining signals such as:

```text
hotspot activity
crop drought stress
optical satellite observations
SAR-enabled disaster observations
rainfall
humidity
wind
terrain
slope

community and infrastructure exposure
```

The output is not only a map layer.

The output is a decision-support priority result:

```text
priority_score
severity
recommended_action
risk_drivers
operator_summary
```

---

# Recommended Product Sentence

```text
DisasterGuard is a multi-sensor disaster-priority intelligence layer that complements existing disaster-monitoring systems by ranking which geolocated risk areas should receive earlier review, revisit, alerting, or response coordination.
```

---

# What to Avoid Saying

Avoid:

```text
We replace GISTDA’s existing platforms.
We predict disasters with certainty.
We provide the final emergency-response decision.
We are building another hotspot map.
We are building another crop drought map.
```

Use instead:

```text
We support prioritization.
We help operators focus attention.
We rank risk areas.
We explain the drivers.
We recommend review or response coordination.
```
