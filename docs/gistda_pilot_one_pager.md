# DisasterGuard GISTDA Pilot One-Pager

## Overview

DisasterGuard is a multi-hazard decision-priority layer for disaster-risk review in Northern Thailand and ASEAN contexts. It combines normalized hazard, exposure, urgency, confidence, and explainable risk drivers into a compact priority result for operator review.

DisasterGuard is designed to complement existing GISTDA capabilities and partner systems. It does not replace fire hotspot monitoring, crop drought / vegetation stress monitoring, THEOS-2 imagery workflows, SAR-enabled disaster monitoring, weather data, terrain data, or existing operational decision processes.

## Target Use Cases

- Wildfire / haze priority: hotspot escalation, vegetation stress, dryness, wind spread potential, and community exposure.
- Rapid flood priority: rainfall intensity, surface water expansion signals, low-lying terrain, river proximity, road exposure, and community exposure.
- Landslide priority: heavy rainfall, terrain / slope, soil saturation proxy, land-cover disturbance, road exposure, and settlement exposure.
- Crop drought / vegetation stress as an upstream signal: dryness and vegetation stress can support wildfire / haze review and future multi-hazard prioritization.

## Expected Pilot Value

- Prioritize which geolocated areas deserve earlier review, revisit, alerting, or response coordination.
- Explain the main risk drivers behind each priority result.
- Support faster coordination by presenting score, severity, recommended action, and operator summary in one view.
- Provide a lightweight structure for testing how multiple data layers could support GISTDA-style stakeholder review.

## Positioning

The pilot should be presented as decision-priority support. It is not a deterministic disaster prediction system and should not be described as replacing existing GISTDA systems.
