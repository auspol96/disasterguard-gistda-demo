# Data Source Mapping

## Wildfire / Haze Priority

Hotspot points, hotspot age, vegetation stress, dryness, humidity, wind, forest boundary, recurrence, and community exposure.

## Rapid Flood Priority

Rainfall, river proximity, low-lying terrain, surface-water expansion, soil saturation proxy, and infrastructure exposure.

## Landslide Priority

Rainfall, slope angle, elevation, soil moisture proxy, land-cover change, and road or community exposure.
